## Featured project

**[موعد (Maw'id)](https://github.com/FaisalAlMass/meetmind)** — a
bilingual (Arabic/English) smart calendar assistant. Type or speak an
event in plain language, in either language, relative or absolute
dates, Hijri or Gregorian — the app understands it, flags anything
it's unsure about, and confirms before saving anything. Cloud-synced
via Firebase, with a native iOS home screen widget.

## Stack
